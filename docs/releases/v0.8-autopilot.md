# Lenaba v0.8 — Autopilot Data Engine

**Release:** `v0.8-autopilot`

**Sprint:** 8

**Status:** Stable

---

## Overview

Version **0.8 Autopilot** marks the transition of Lenaba from a collection of parsing scripts into a self-managing **Name Knowledge Engine**.

The system now automatically prioritizes work, resumes interrupted sessions, enriches existing records, verifies families against BehindTheName, discovers new names, and operates with human-like pacing suitable for long unattended runs.

### Incremental Knowledge Updates

Every processed family now follows the same pipeline:

`Cache → Master → Family Merge → Verification → Candidate Discovery`

Only missing fields are written, making reruns safe.
